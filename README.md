# Sajid Al Raian — Portfolio Website

A responsive personal portfolio built with HTML, CSS, and JavaScript in a clean white-and-blue visual style.

## Included
- Responsive landing page and mobile navigation
- About, skills, education, experience, projects, and contact sections
- Project detail pages
- Subtle motion effects with reduced-motion accessibility support
- Contact form that opens the visitor's email application (no backend required)

## Deploy / update on Netlify
1. Extract this ZIP.
2. Open your Netlify site dashboard.
3. Go to **Deploys** and drag the extracted `sajid-portfolio` folder into the manual deploy area (or connect the folder's Git repository).
4. After deploy finishes, open the live site and test it on both desktop and mobile.

## Before sharing widely
- Add genuine screenshots of each project when available; don't use placeholder images as if they were real app screenshots.

- Add a resume PDF only after you have a current version ready.
